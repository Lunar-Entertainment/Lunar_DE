# Lunar DE Antigravity Plugin

Gives Gemini models in Antigravity direct, safe MCP tools to inspect and control your Linux PC and Lunar DE session.

## Included Tools
- `get_system_info` — Monitors, RAM, disk, volume, and active display
- `list_windows` — List open X11 windows
- `launch_app` — Search and launch installed desktop apps
- `window_action` — Focus, close, maximize, or snap windows
- `take_screenshot` — Capture the desktop screen to PNG
- `set_volume` — Set volume percentage or toggle mute
- `set_wallpaper` — Switch wallpapers or enable `CYCLE_ALL`
- `set_bar_layout` — Switch between `top` (Top Bar), `taskbar` (Bottom Taskbar), and `taskbar-top` (Top Taskbar)
- `send_input` — Send keystrokes or clicks via `xdotool`
